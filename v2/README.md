# AI Video Maker V2 — Clean Studio

Status: BUILDING
Branch: `v2-clean-studio`
V1/main remains untouched as the fallback.

## Product goal

One prompt → AI Director → reusable character/world references → scene assets → video/audio → timeline → QC → export → publishing package.

The studio must also allow users to stop at any stage and keep/export an individual asset (for example, a generated still image) without creating a video.

## Locked principles

1. **$0-first.** Free/local/open-source/free-tier providers are preferred. Paid providers are opt-in only and must never run or charge automatically.
2. **Non-destructive.** Preserve V1, autosave projects, version important state, and regenerate only the selected asset/scene.
3. **Provider-independent.** Image, video, voice, lip-sync, music/SFX and upscale providers use adapters so they can be replaced without rebuilding the UI.
4. **Capability honesty.** UI must distinguish requested quality from provider-confirmed capability. Never label an output 4K, native-audio, photorealistic, etc. unless the selected pipeline actually supports it.
5. **Flexible creativity.** Photorealistic, cinematic, 3D, cartoon, storybook, fantasy, sci-fi, surreal/impossible and custom directions are supported.
6. **Asset ownership workflow.** Every generated asset can be kept, locked, exported, reused as reference, replaced, or animated later.

## Quality targets

- Photorealistic / real-footage visual direction when requested
- Smooth temporal motion and anti-flicker QC
- Character identity/wardrobe/age consistency
- Structured prompt interpretation and scene requirements
- Natural lighting, shadows, contacts and object-interaction checks
- Scene-to-scene story continuity
- 1080p final pipeline; 4K upscale/export only when a capable route exists
- Expression direction and provider-backed lip-sync
- Modular voice, SFX, ambience and music
- Draft/preview rendering for speed before final-quality rendering

These are **targets**, not fake guarantees: actual generation quality depends on the active model/provider and source material.

## Asset actions

Each image/video/audio item supports:

`KEEP` · `LOCK` · `EXPORT` · `USE AS REFERENCE` · `REGENERATE` · `ANIMATE LATER`

Locked assets must not be regenerated by whole-project operations.

## Cost modes

Initial V2 default: **FREE ONLY**

Future selectable modes:
- FREE ONLY
- LOWEST COST
- FASTEST
- BEST QUALITY

Any mode capable of spending money requires explicit owner opt-in before provider execution.
